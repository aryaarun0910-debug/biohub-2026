# Reports

The active report surface is intentionally small:

- `NEXT_DECISION.md` — current hypothesis, gates, and execution order.
- `EXPERIMENT_LEDGER.md` — compact closed-method ledger and recovery map.
- `METRIC_SEMANTICS_VERIFIED.md` — verified scorer behaviour.
- `journal/JOURNAL.md` — chronological experiment record.
- `inventory/` — only canonical machine-readable results used by the active handoff.

The former collection of dated plans, research lanes, Codex/Claude transfer messages,
figures, and dead runbooks is available at Git tag `pre-lean-2026-07-30` (commit
`7897511`). Those files are historical evidence, not current instructions.
