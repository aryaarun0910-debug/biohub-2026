### Spotiflow recipe (Codex, adopted)
- Spotiflow 0.6.5 from synth_3d/smfish_3d (whichever wins zero-shot complement recall).
- **Residual detector**: 50% patches centered on DoG-MISSED annotated cells, 25% any annotated cell,
  25% random/high-uncertainty. Keep 25% ordinary annotated to avoid pathological specialization.
  Union learned candidates with DoG; NEVER replace DoG.
- Resample ~0.8125 um isotropic (XY /2, Z x2). Patch 48x96x96. AMP.
  A100: batch 2-4 + grad-accum. Heatmap target Gaussian sigma~1.2 um.
- **Sparse mask**: weight 1.0 within ~3 um of an annotation, 1e-6 outside; NORMALIZE pos/neg loss
  mass separately; flow loss only near positives; do NOT mark visible unannotated nuclei as background.
- AdamW wd 1e-4; 2k steps freeze backbone (heads LR 3e-4); then backbone 3e-5 / heads 1e-4;
  15-25k steps; 500 warmup, cosine, EMA 0.999. Eval every 1k via union->arbitration->exact edge metric.
- Physical aug only (flips, 90deg XY rot, gamma 0.7-1.5, contrast/brightness, gauss/poisson noise,
  blur 0-1.2um, depth attenuation, photobleach ramp, missing Z planes, scale 0.9-1.1). NO arbitrary 3D rot.
- **Fold protocol**: Model A train 6bba/val frozen 44b6; Model B train 44b6/val frozen 6bba. Only if
  ONE config improves BOTH folds -> final model on both. No public-LB hyperparameter selection.
